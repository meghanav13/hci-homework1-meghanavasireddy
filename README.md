# HCI Homework 1 – Course Planning UI

This repository contains a static HTML/CSS implementation of the course detail screen
for mobile course planning application designed to improve how Penn students decide what courses to take.

## How to Run
Open `index.html` in a web browser. No additional setup is required.

## Attributions
The code in this repository was partially created using AI generation and then manually adapted into static HTML and CS for the purposes of this assignment.
